# XeroxChat - Production-Grade Real-Time Chat Application

A production-ready real-time chat application built with **Node.js, Express.js, Socket.IO, and TypeScript**.

## Features

- Real-time messaging using Socket.IO
- Multiple chat rooms
- User management
- Responsive UI
- TypeScript support
- Zod validation
- Structured logging
- Unit testing with Vitest
- XSS protection
- Graceful shutdown handling

## Tech Stack

- Node.js
- Express.js
- Socket.IO
- TypeScript
- Zod
- Vitest
- Webpack
